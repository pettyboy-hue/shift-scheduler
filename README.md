# 📅 排班管理系统 — 大小休三班制

一个纯前端的智能排班工具，专为大小休 + 三班制企业设计。

## ✨ 功能特性

- **大小休自动编排**：一周双休（大休）、一周单休（小休）交替
- **三班次覆盖**：早班 09:00-18:00 / 中班 16:00-次日01:00 / 晚班 21:00-次日05:00
- **24小时不断人**：周末自动安排值班，休息日每班减半
- **人性化排班算法**：
  - 🚫 避免晚班后接早班（只有4小时休息）
  - 🚫 尽量避免中班后接早班（只有8小时）
  - ✅ 连续工作≥6天强制降优先级
  - ✅ 工时公平分配，班次均衡
  - ✅ 双休日尽量安排连休
- **手动微调**：点击日历格子可修改任意员工班次
- **双视图**：日历视图 + 列表视图
- **导出 CSV**：支持导出排班表到 Excel
- **本地保存**：员工数据自动保存到浏览器

## 📐 排班算法说明

### 分组策略
- 员工平均分为 A、B 两组
- A 组大休周时 B 组小休，下一周反过来
- 保证每周都有足够人手

### 值班安排
- **工作日**：每班次 2 人（可配置）
- **休息日**：每班次 1 人（可配置）
- 大休周的周六日：从工作组中安排值班覆盖

### 智能评分
每次分配班次时，对所有候选人打分（分数越低越优先）：
| 因素 | 权重 | 说明 |
|------|------|------|
| 晚班→早班 | +1000 | 严格禁止，4小时休息不够 |
| 连续工作≥6天 | +500 | 强制降级，保障休息 |
| 连续工作≥5天 | +200 | 适度降级 |
| 中班→早班 | +100 | 尽量避免 |
| 总工作天数 | ×10 | 保证工时公平 |
| 该班次累计 | ×5 | 均衡各班次分配 |
| 随机扰动 | 0~3 | 避免排班死板 |

## 📋 使用指南

1. **添加员工**：在左侧面板输入姓名添加（或点「加载示例员工」快速体验）
2. **配置参数**：选择月份、第一周类型、每班人数
3. **生成排班**：点击「生成排班表」
4. **查看结果**：日历视图看概览，列表视图看每人明细
5. **手动调整**：点击任意日期格子，弹窗修改个人班次
6. **导出**：点右上角「导出」下载 CSV 文件

## ⚠️ 员工人数建议

- 开启晚班（3班次 × 每班2人）：**至少 6 人**，建议 **10-12 人**
- 关闭晚班（2班次 × 每班2人）：**至少 4 人**，建议 **8-10 人**

人数越多，排班越灵活，员工休息越充分。
