# 📅 排班管理系统

> 大小休 · 三班制 · 自动编排

## 功能

- ✅ 大小休自动轮换（一周单休 + 一周双休）
- ✅ 早班/中班/晚班三班次覆盖 24 小时
- ✅ 工作日每班 2 人，休息日每班 1 人
- ✅ 双休日连休保障
- ✅ 避免晚班转早班
- ✅ 手动调整任意排班
- ✅ 导出 CSV
- ✅ 本地保存配置

## 使用

访问 GitHub Pages 地址即可使用，无需安装。

## 班次

| 班次 | 时间 |
|------|------|
| 早班 | 09:00 - 18:00 |
| 中班 | 16:00 - 次日01:00 |
| 晚班 | 21:00 - 次日05:00 |
